# AmoTool

**amoCRM — Задачи + SMS + Звонки**

Десктопное приложение для Windows: выгружает задачи из amoCRM, отправляет SMS мастерам и клиентам (включая массовую рассылку по расписанию), помогает в обзвоне, а при входящем звонке автоматически открывает карточку клиента в браузере — или форму нового клиента, если номера нет в базе.

## Возможности

### amoCRM
- Авторизация через Selenium. Сбор задач, рассылка и обзвон работают в одном профиле Chrome, окно входящих звонков — в своём отдельном.
- Парсинг задач по мастерам и по клиентам, фильтрация по дате/отделу.
- Хранение логина/пароля в Windows DPAPI (зашифровано на диске).

### SMS
- Отправка одиночных SMS мастерам и клиентам с подстановкой шаблонов.
- **Массовая рассылка** по задачам «СМС» с прогресс-баром и логом.
- **Авто-расписание** массовой рассылки: чекбокс «Запускать автоматически в HH:MM» в Настройки → Рассылка. Раз в день в указанное время AmoTool сам стартует рассылку.
- Шаблоны сообщений с подписями отделов «Север» / «Юг».
- `tel:`-хендлер: клик по номеру в карточке amoCRM инициирует звонок на твоём Android-телефоне (через помощник `AmoCaller.exe`).

### Обзвон
- Пошаговое открытие карточек задач «Звони» с автоматической раскладкой окон.
- Автоматическая постановка задач «Недозвон» с описанием.

### Входящие звонки
- Слежение за входящими через Android-сервер (NotificationListener + PHONE_STATE broadcast).
- **Отдельное окно браузера.** Входящие открываются в собственном окне Chrome со своим профилем и своей сессией amoCRM. Оно не зависит от рассылки и обзвона и работает параллельно с ними.
- **Клиент есть в базе** — AmoTool находит его по номеру и открывает карточку. Каждый звонящий — в своей вкладке, чтобы не закрыть карточку, с которой оператор уже работает.
- **Номера нет в базе** — открывается форма нового контакта: телефон уже вписан, тег «Сервис» поставлен, курсор стоит в поле имени. Вкладка подписана номером звонящего.
- **После «Сохранить»** AmoTool сам создаёт сделку «Имя//» на стадии «Переговоры» с тегом «Сервис» и отправляет клиенту SMS с текстом из Настройки → Рассылка. Если оператор нажал «Отмена» или закрыл вкладку — ничего не создаётся.
- Повторный звонок с того же номера не открывает новую вкладку, а показывает уже открытую.
- Toast-уведомление в Windows при каждом входящем звонке.

### Системный трей
- Иконка в трее с меню: «Показать окно / Слежу за входящими / Выход».
- Кнопка «×» сворачивает в трей (опционально, по флагу в настройках).
- Toggle слежения за входящими прямо из меню трея.

### Авто-запуск с Windows
- Опция в настройках прописывает AmoTool в `HKCU\…\Run` с флагом `--tray` — приложение стартует свёрнутым при логине пользователя.

### Инфраструктура
- Автообновление через GitHub Releases с проверкой SHA256.
- Двухветочная релизная модель (`master` для разработки, `release` для тегов) через скрипт `release.ps1`.
- Покрытие 100+ юнит-тестами (`tests/test_core.py`).

## Архитектура

```
PC (Windows)                              Android (отдельный APK)
─────────────────                         ──────────────────────
AmoTool.exe                               CallServer
├─ Tkinter UI + системный трей            ├─ HTTP-сервер :8088
├─ Selenium → Chrome → amoCRM             │   ├─ POST /call
├─ Шифрованные настройки (DPAPI)          │   ├─ POST /sms
└─ HTTP-клиент → Android-сервер           │   └─ GET  /events?since=…
   ├─ POST /call          ── inициация    ├─ NotificationListener (входящие)
   ├─ POST /sms           ── отправка     └─ PHONE_STATE broadcast (fallback)
   └─ GET  /events        ── polling
                            (входящие)

AmoCaller.exe (отдельный helper, ставится один раз)
└─ Обрабатывает tel:-клики из браузера → POST /call на Android
```

## Установка

### PC
1. Скачать `AmoTool.exe` из последнего [GitHub Release](https://github.com/PavelSirotkin/AmoTool/releases).
2. Запустить, заполнить настройки (логин/пароль/URL amoCRM, IP-адрес Android-телефона).
3. Опционально: скачать `AmoCaller.exe` рядом с `AmoTool.exe`, в настройках включить «Перехватывать tel:».

### Android
1. Установить APK `CallServer-<version>.apk` (собирается из репозитория `Android`).
2. Выдать разрешения: **Телефон**, **SMS**, **Журнал вызовов**, **Доступ к уведомлениям**.
3. На MIUI/HyperOS дополнительно: разрешить **Автозапуск** в приложении «Безопасность».
4. Запустить сервер из главного окна — увидишь IP-адрес и порт.

## Технологии

- **Python 3.14**, Tkinter, Selenium, BeautifulSoup, pystray, Pillow.
- **PyInstaller** для сборки `.exe`.
- **Kotlin / Android Gradle Plugin 8.x** для CallServer.
- **NanoHTTPD** на Android-стороне.

## Разработка

```bash
# Установка зависимостей
py -m pip install -r requirements.txt

# Запуск из исходников
py main.py

# Тесты (141+)
py -m unittest tests.test_core

# Релизный билд
.\release.ps1 -Version X.Y.Z -Notes "Описание изменений"
```
